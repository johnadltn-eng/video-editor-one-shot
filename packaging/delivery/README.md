# Delivery

`ship.sh` is the script the older release notes expected to publish a download. That publisher was not in the pinned source tree. The script in this directory always refuses. It does not upload, open a page, or change an external site.

Run the Mac smoke check in `../gates/MAC-SMOKE.md` before anyone records a download or a successful setup. A passing local record still does not make `ship.sh` publish.
